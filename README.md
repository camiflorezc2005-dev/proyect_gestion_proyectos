La aplicación web presentada tiene como finalidad la gestión de trabajos y proyectos de grado dentro de una institución universitaria. Este sistema permite el registro de los proyectos por parte de los estudiantes, la administración por parte de los coordinadores y directores, y la evaluación por parte de los jurados, logrando así un control sobre entregables, fases y retroalimentación de cada uno de los procesos.

1. Características principales

- Registro de proyectos por usuarios estudiante.

- Carga y control de entregables en fases (anteproyecto, desarrollo, sustentación).

- Asignación y gestión de directores y jurados.

- Evaluación de proyectos por jurado: calificación y retroalimentación detallada.

- Visualización y descarga de actas finales y certificados.

- Interfaz adaptada a roles (estudiante, coordinador, director, jurado).

2. Tecnologías utilizadas
   
- HTML5 y CSS

- JavaScript 

- No requiere backend: datos almacenados en memoria del navegador

3. Estructura de roles

- Estudiante: Registra proyectos, sube entregables, recibe observaciones.

- Coordinador: Asigna directores y jurados, programa fechas, genera actas.

- Director: Supervisa, revisa entregables, emite observaciones.

- Jurado: Evalúa los proyectos asignados, asigna calificación y retroalimenta.
